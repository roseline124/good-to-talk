# Install Good To Talk with your AI agent

Copy the prompt below into your AI assistant **with this GitHub repository link**:

```text
Please install the Good To Talk Agent Skill from:
https://github.com/roseline124/good-to-talk

Read its SKILL.md and register it using the official skill installation method supported by your environment.
If your environment permits, perform the installation yourself.
If you cannot persistently install skills, read SKILL.md and apply its behavior in this conversation instead.
Report clearly whether installation succeeded, was applied only to this chat, or was unavailable.
Do not request email account access. Do not send any emails.
```

## 한국어 복붙 프롬프트

```text
https://github.com/roseline124/good-to-talk 에 있는 Good To Talk 스킬을 설치해줘.
SKILL.md를 읽고 네 환경이 지원하는 공식 스킬 설치 방식으로 직접 등록해줘.
영구 설치가 불가능하다면 이번 대화에만 지침을 적용하고 설치 여부를 솔직히 알려줘.
메일 계정 연결이나 자동 발송은 필요 없어.
```

> Compatibility varies. Some assistants can fetch the repository but cannot persist installed skills. They can still follow the instructions temporarily if they can read SKILL.md.
